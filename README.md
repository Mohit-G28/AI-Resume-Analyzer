# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer web application that analyzes resumes, detects skills, calculates ATS compatibility, matches resumes with job descriptions, identifies missing skills, and provides improvement suggestions.

## 🚀 Features

- 📄 PDF and DOCX resume upload
- 📊 ATS compatibility score
- 🎯 Job description matching
- 🛠️ Automatic skills detection
- ❌ Missing skills identification
- ✅ Matched skills detection
- 💡 Resume improvement suggestions
- 📈 Interactive resume dashboard
- 📋 Analysis summary
- 📱 Responsive and modern UI
- ⚡ Flask-based backend
- 🔄 Real-time resume analysis
